# Intelligent Data Quality Platform

A small Python project that loads a CSV file, checks its data quality, and writes the findings to a CSV report.

## Project structure

```text
.
├── data/
│   └── sales_data_500_rows.csv
├── reports/
│   └── validation_report.csv   # Generated by main.py
├── src/data_quality/
│   ├── ingestion.py
│   └── validators.py
├── tests/
│   └── test_ingestion.py
├── main.py
└── pytest.ini
```

## Validation checks

`main.py` loads `data/sales_data_500_rows.csv` and runs these checks:

- Missing values in each column.
- Positive values in integer columns.
- Non-negative values in floating-point columns.
- Duplicate values in `TransactionID`.
- Empty strings, whitespace-only strings, and leading or trailing whitespace in text columns.

The console output identifies each rule and column, whether issues were found, and the affected row indexes. The detailed report includes the reported row number, DataFrame index, column, rule, error type, description, and offending value. Reported row numbers start at 1.

## Run the validation

From the project root, run:

```bash
python main.py
```

The report is written to `reports/validation_report.csv`, replacing the previous report each time the script runs. The input CSV path is set near the start of `main.py`.

## Run the tests

Install the dependencies if needed:

```bash
python -m pip install pandas pytest
```

Run all tests from the project root:

```bash
python -m pytest
```

In VS Code, open the **Testing** view and choose **Run Tests**. The workspace pytest settings and `pytest.ini` configure discovery under `tests/`.
